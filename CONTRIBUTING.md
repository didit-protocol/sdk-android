# Contributing

## Protect private information

This repository is public. Do not include customer, prospect, organization, or
contact names; email addresses; account/session identifiers; private support
details; private tracker keys; or links to private repositories and internal
tools in issues, pull requests, comments, commits, screenshots, logs, fixtures,
release notes, or Maven metadata. Describe a report anonymously and share
identifying context with maintainers only through an approved private channel.

## Releases

Release changes must go through a pull request. Verify that all six modules,
their POM dependencies, Maven metadata, and checksums use the same version
before tagging the reviewed merge commit.
